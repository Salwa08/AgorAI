# FarmSwarm EXP002 — harmful-information diagnostics

Dependent research branch: research/exp002-negative-transfer-diagnostics, based on EXP001 9564602. The draft PR targets research/exp001-social-learning-ablation and must not be merged independently into main. V1 and EXP001 remain unchanged.

Read RESEARCH_PLAN.md (committed before implementation), METHODOLOGY.md, and RESULTS.md. All results are conditional simulation evidence.

## Execute from repository root

Use EXP001's tested direct dependency pins and Python 3.12.4:

```powershell
python -m pip install -r experiments/exp001/requirements-lock.txt
python -m pytest experiments/exp001/tests experiments/exp002/tests -q
python -m experiments.exp002.runner --config experiments/exp002/configs/smoke.json --output experiments/exp002/results/replay/smoke
python -m experiments.exp002.runner --config experiments/exp002/configs/full.json --output experiments/exp002/results/replay/full
```

Output directories must not already exist; use fresh paths for subsequent runs. Each config specifies agent count, season count, explicit seeds and the complete fixed arm list. The full config uses 100 farmers × 30 seasons × 20 seeds × 16 arms. The smoke config uses six farmers × three seasons × two seeds. The runner prints each completed seed/arm and fails on exogenous-pairing mismatch. Do not interpret a partially written directory as a completed run; metadata.json is written only after all arms and aggregates finish.

## Importable model

```python
from experiments.exp002.model import Config, run_sim
model, outcomes = run_sim(Config(
    n_agents=100, n_seasons=30, random_seed=0,
    social_information_enabled=True,
    deduplicate=True,
), tracing=True)
```

Diagnostic switches default to EXP001 behavior. epsilon is restricted to information-off worlds. context_filter must be same_zone, unrestricted or ecological; EXP001's inherited knowledge_filter_mode stays at filter to avoid ambiguous competing switches. profit_per_ha changes only the zone profit signal; own_memory_only changes only the experience scoring pool; deduplicate acts within scoring pools; zone_yield_fraction controls only the zone yield/profit mixture.

## Outputs and provenance

raw/ contains compressed outcomes, decision/candidate traces and immutable harvest ledgers per seed/arm, plus one exogenous environment per seed. Decision traces include post-decision analyst-only candidate potential profits; these must never be supplied back to agents. Trace paired_A fields and raw outcome deltas refer to original A, while summary contrasts also include appropriate B or exploratory-A references.

agents.csv averages each identity's seasons; seed_summary.csv and levels.csv contain outcome/harm/severity/switching endpoints by seed/zone and their seed uncertainty. contrasts.csv distinguishes the prespecified 48-test Holm family from exploratory comparisons. harm_groups.csv compares outcome-selected groups descriptively; crop_pairs.csv attributes paired effects to baseline-versus-chosen crops; switch_transitions.csv records actual temporal switches; season_zone.csv describes timing. exp001_reproduction.csv retains A–D results for comparison with EXP001. Configs, resolved settings, run_manifest.json, and metadata.json record execution evidence.

Large raw traces and tables are reproducible and ignored by Git. Compact summaries, verification and research reports are retained for review. Original 500-mm fallback is preserved. No adaptive trust, reinforcement learning, crop-data changes or empirical agricultural claims are introduced.

After the full run, verify and regenerate diagnostics/report:

```powershell
python -m experiments.exp002.diagnose --results experiments/exp002/results/replay/full
python -m experiments.exp002.report --results experiments/exp002/results/replay/full
```

The report links INTERPRETATION.md, the scientific assessment written after all original runs completed. Report generation requires the full prespecified configuration and completed raw outputs. The smoke run tests the pipeline and is not a basis for scientific inference.

analysis_metadata.json separately records downstream diagnostic script and derived-output hashes. The simulation metadata retains the source snapshot at execution time; later report edits are not claimed to have preceded execution. case_study.json is regenerated by diagnose using an explicitly post-hoc selection rule.
