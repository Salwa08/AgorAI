# EXP004 protocol: value of collective evidence

## Status and repository audit

Protocol written before implementation or pilot outcomes. Independent branch from main (6be6ced); inspected EXP001 model/tests and EXP002 model, methodology and tests on their research branches. EXP002 imports EXP001 and preserves its agricultural assumptions; main has no experiments package. Neither is a suitable dependency for an independent information benchmark. EXP003 is not implemented in the inspected branches. No agricultural input or frozen experiment is modified. NumPy, SciPy and pytest already occur in repository dependencies; no service, LLM or learning framework is required.

## Question and falsifiable hypotheses

When does additional evidence improve individual decisions after accounting for context, preferences, uncertainty and transmission cost? Correct information is not necessarily relevant; relevant information is not necessarily decision-improving. Raw outcomes are never replaced by the sender's preferred action or scalar utility.

H1: pooling complementary, unbiased observations reduces expected regret in S1 at zero communication cost, including under heterogeneous preferences. H2: ignoring decision-relevant contexts in S2 can increase regret; exact context conditioning should improve on naive pooling on average. H3: duplicate evidence in S0 gives exactly no decision gain after provenance deduplication. H4: positive transmission cost can reverse net gains. H5: centralized and distributed implementations using identical evidence/estimators make identical decisions; differences in costs arise from the declared transmission topology, not superior intelligence. Failures are reported, not tuned away. No claim that every sharing method or seed must improve.

## Generative model

Default N=20 agents, K=3 actions, D=3 outcome dimensions, C=3 categorical contexts, T=100 rounds, seeds 0..19. All outcome dimensions are standardized abstract benefits; higher is better. No currency or agricultural units. Contexts c_i are a randomly permuted balanced assignment; preference vectors w_i ~ Dirichlet(1,1,1), fixed within seed, sum to one, nonnegative. Quality multiplier q_i is randomly permuted alternating .5 and 1.5. Agent IDs persist for harm summaries, but round environments and measurement noise are independent conditional on this population.

For round t/action a/dimension d, draw g_tad and h_tcad independently N(0,1). Latent expected outcome is mu_tcad = sqrt(1-rho^2) g_tad + rho h_tcad. S1 rho=0 (contexts are irrelevant); S2 rho=1 (contexts differ independently). This deliberately simple contrast changes only latent contextual dependence, using the same primitive draws. No guaranteed winning action or policy is encoded. Shared component and context offsets have the same marginal variance, 1, in both regimes.

Each agent observes one uniformly randomized action a_it before deciding, independent of outcomes. It receives the entire three-dimensional vector y_it = mu_tc_i,a_it + sigma q_i epsilon_it, epsilon ~ N(0,I). sigma is .5 or 1.5 (quality sensitivity). Measurement variance (sigma q_i)^2 is known from a declared calibration assumption and attached to the message. Evaluation potential outcomes z_ita = mu_tc_i,a + .2 eta_ita are independently drawn after training measurements, for ALL actions; eta ~ N(0,I). Policies never observe mu, rho, g, h, eta, z or the scenario label. All actions feasible for every agent. No history is carried across rounds and there is no training on evaluation outcomes.

S0 no-gain control: rho=0; all agents already possess the SAME three independent noisy public measurements (one per action, variance sigma^2), with identical provenance IDs. Relaying copies adds no unique evidence. This is intentionally redundant evidence, not twenty independent measurements with equal values. S0 changes the observation design and is a sanity control, not an isolated rho contrast.

## Information interface and estimator

Immutable messages carry identity (seed, round, origin, sample index), origin context, action, three raw outcomes, and measurement variance. Origin -1 denotes public S0 evidence valid across contexts. Receivers deduplicate identical IDs; conflicting payloads for an ID are errors. Equal values with different IDs remain distinct. Policies receive only their own context/weights, permitted messages, and the declared N(0,1) marginal prior. Prior and noise calibration are public assumptions, not fitted hidden outcomes. Incoming scope is checked against seed/round. Policy modules cannot import the environment/evaluator. This is an auditable API boundary, not a security sandbox against malicious Python.

For each action and dimension, independent conjugate Gaussian updating uses posterior mean m_a = sum_j(y_j/v_j)/(1+sum_j 1/v_j), posterior variance V_a=1/(1+sum_j 1/v_j); no evidence gives m_a=0,V_a=1. Choose argmax_a w_i dot m_a; ties choose smallest action. This is correctly specified within a compatible context (and globally in S1). Preference changes reweight the same raw vector and do not change the observation likelihood. Biased measurements, incorrect variance reports and dishonest origins are NOT modeled; contextual pooling misspecification must not be described as evidence bias or preference mismatch.

## Baselines and budgets

B0 local-only: own messages only; cannot read peers; zero transmission.
B1 always-share: receive every other agent's messages and pool without context conditioning; use receiver weights.
B2 context-filtered: receive only messages from exactly equal contexts, plus public S0 messages; pool with the same estimator and weights. Context labels assumed known for free, routing excludes rejected messages before payload delivery.
B3 centralized: each agent uploads its own messages once; service conditions on recipient context exactly as B2 and uses each recipient's weights. Same permitted UNIQUE evidence and estimator as B2, no latent access. B2/B3 equality is a required control. B3 is a strong stratified estimator in S2 but unnecessarily discards useful cross-label evidence in S1. It is not granted knowledge of which regime applies.

Transmission unit is one three-dimensional observation payload, excluding fixed metadata overhead. B1/B2 charge each sender-to-recipient delivery, even if a duplicate is detected after receipt. Costs are attributed to recipients. B3 totals all uploaded payloads plus N reply packets (each charged one payload-equivalent); equal allocation across agents gives system cost/N. Local acquisition is equal and uncharged. Objective/context metadata, processing, coordination, delay, compression and broadcast savings are unmodeled. Central cost advantage is topology-assumed, not measured infrastructure performance. Charge lambda in {0,.01,.1} utility units/payload-equivalent; decisions remain unchanged by lambda (fixed policies, no optimized communication selection). Costs are postprocessed on identical actions, not independent runs. Also report evidence volume and posterior uncertainty.

## Evaluation and uncertainty

Primary: expected regret R_it = max_a(w_i dot mu_tc_i,a) - w_i dot mu_tc_i,chosen. Secondary realized regret uses max_a(w_i dot z_ita) - w_i dot z_it,chosen, an unattainable hindsight reference; never call this expected regret. Report expected and realized utility, net expected utility U-lambda*volume, expected utility harm and net harm versus paired B0, q10 of each agent's round-mean expected utility, posterior uncertainty and transmissions. Expected regret is nonnegative, excludes communication cost and has evaluation-only oracle zero. No deployable oracle policy is needed.

Average rounds within agent first. Harm means this mean expected utility is below matched B0 by >1e-12; net harm similarly. Also retain round-level harm as a separate descriptive metric. Seed means give each agent equal weight; subgroup reports use context and dominant utility dimension (argmax w_i). Seeds are independent replicates; agents and rounds are not inferential replicates. For all endpoints and paired policy-minus-B0 effects, report mean across 20 seeds and two-sided 95% Student t intervals using sample SD / sqrt(n). Missing subgroup seeds explicitly counted; n<2 gives no CI. Intervals are exploratory and unadjusted across comparisons; no significance-based ranking or confirmatory p-values. Keep both utility and regret contrasts, allowing arithmetic checks. Compare B2-B1 and B3-B2 using paired seed effects as mechanism checks.

## Reproducibility and execution order

Commit this protocol first. Implement fixed semantic RNG streams for population, round latent means, observation choices/noise and evaluation noise, matched across policies and scenario/noise sensitivities. Never use Python randomized hash as RNG seed. Run smoke before pilot. Retain configuration, exact seeds, Python/package/platform versions, source hashes, commit and dirty state, output hashes, per-agent summaries and seed results. Raw round outputs and message audit ledgers may be compressed and ignored; content deterministic, compression headers need not be. Run tests before interpreting the pilot. No tuning from pilot winners. Numerical tolerances are tests of implementation, not criteria for scientifically favorable findings.

## Tests, failure criteria and limits

Test deterministic replay; restricted policy interface; hidden-state/evaluation perturbation invariance; objective-respecting decisions; exact provenance/dedup; scope rejection; costs and regret by hand; identical matched worlds; B0 peer invariance; B2/B3 equality; S0 exact zero decision gain; zero observations; identical preferences; high noise; incompatible contexts. Monte Carlo conjugate-model test checks zero-cost additional correct evidence does not systematically worsen expected utility for heterogeneous objectives (allow sampling error, not per-realization dominance). Stop interpretation on boundary, accounting, pairing or sanity violations and document corrections before expanding runs.

This benchmark is synthetic, stationary within each round, has known Gaussian likelihoods/prior, calibrated quality, exact contexts, fixed communication graphs, independent outcome dimensions, linear utilities and no strategic competition. Context heterogeneity is engineered, but its effect comes from an explicit estimator misspecification, not harmful accurate raw evidence by definition. Low realized utilities can reflect irreducible noise. Utility scale determines cost thresholds. No field validation, agricultural prediction, water-model claim or novel goal-aware transfer method. Readiness for a new selector requires these controls to pass; general superiority requires new scenarios, baselines and held-out confirmation seeds beyond this exploratory pilot.
